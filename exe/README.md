# CoA64.exe with the plugin loader

Built by aspollon for CoA Custom 1.9.9 (`COA-CUSTOM-VERSION.txt`) from ilusixn/CustomRacesCoa tag `coa-custom-1.9.9`
plus six commits (CoA64 commit d997b15): the `Plugins\*.dll` loader, HD on any renderer, the LuxVelum host (the
HD pack's `LuxVelum64.dll`: fog, light and water, idle without the dll), add-on music through `PlayMusic` (silent
before), and the twelve AllRaces v12 pack races (Sureki, Dreadlord, Titan, Wretched, Fungarian, Sporeling, Stormforged, Mo'arg, Nerubian, Lich, Mogu,
Lost One) with their Esteria ids, banks and options, as in ilusixn's 1.9.9 exe. Shipped with ilusixn's permission.
AFK Realm installs it (voices, HD pack page, CoA Custom setup) whenever the game runs another CoA64.exe.

To update it: build CoA64 (`BuildCoA64.bat`), copy `bin\Win\CoA64.exe` and `XvidDecoder.dll` here, set the CoA Custom
version, commit and tag a new release.
